# bimalkadesilva.github.io

Personal website of Bimalka de Silva — live at https://bimalkadesilva.github.io/

## Updating the site

**Change your photo**
Save your photo as `assets/img/profile.jpg` (replace the existing file). A portrait or square image around 800×1000 px works best. Until a photo is there, the site shows a "BdS" monogram instead.

**Add a project or portfolio piece**
In `index.html`, find the `PROJECTS & PORTFOLIO` comment. Copy the example `<article class="project">` block once per project, fill it in, and delete the "Coming soon" block.

**Edit text**
All wording is in `index.html`. Colours and fonts are at the top of `assets/css/style.css` (`--accent` is the lime highlight colour).

## Publishing
GitHub Pages serves this repository automatically from the `main` branch. After you commit changes, the live site updates within a minute or two.
